
# Compare the Triplets

- Platform: HackerRank
- Language: Java 15
- Difficulty: Easy
- Topic: Basic Implementation
- Status: Accepted

## Approach
1. Initialize Alice's and Bob's scores to zero.
2. Compare their scores at each of the three positions.
3. Increment Alice's score if her value is greater.
4. Increment Bob's score if his value is greater.
5. Return both scores.

## Complexity Analysis
- Time Complexity: O(1)
- Auxiliary Space: O(1)

## Concepts Learned
- ArrayList
- Element-wise comparison
- Conditional statements
- Score tracking
